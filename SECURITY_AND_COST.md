# Security and Cost

## 1. Security (sized for a 3-day project)

| Area | Control |
|---|---|
| Presenter access | Random 32-byte host token, returned once, stored only as SHA-256; constant-time compare; token kept in the URL fragment so it never reaches server or ALB logs |
| Audience abuse | Max 5 questions/min per device, max 300 connections per room, text length limits; text rendered with `textContent` (no HTML), so no XSS |
| Abuse | Room creation is limited to 20 per hour per network address (in memory, per pod, nothing stored; both `POST /api/rooms` and `POST /create`); questions to 5 per minute per device. Behind the ALB the real address is the last `X-Forwarded-For` entry; with no proxy in front, set `TRUSTED_PROXY_HOPS=0` |
| Data | Only an optional display name; rooms and all data deleted 24 h after creation |
| Network | Pods in private subnets; RDS in isolated database subnets, port 5432 only from the node security group; Kubernetes API endpoint limited to your IP (`cluster_endpoint_public_access_cidrs`) |
| Pods | Non-root UID 10001, read-only root filesystem, all capabilities dropped, seccomp `RuntimeDefault`, no service account token mounted |
| Secrets | RDS password generated by RDS in Secrets Manager → K8s Secret by script; nothing secret in git, images or Terraform state. Local overlay uses throwaway credentials marked as local-only |
| CI/CD | GitHub OIDC role trusted only for `main` of this repo; can push to one ECR repo and edit only the `liveask` namespace |
| Images | Immutable tags (git SHA), ECR scan on push |
| Transport | HTTP on the ALB DNS name for the demo. HTTPS with ACM + Route 53 is an optional day-3 task; say so in the README |

## 2. Cost

Development on days 1–2 is free (Docker Compose, minikube). Only day 3 uses AWS.

| Item (ap-southeast-1, approx.) | USD / hour |
|---|---|
| EKS control plane | 0.10 |
| 2 × t3.medium Spot nodes | ~0.03 |
| NAT gateway | ~0.06 |
| ALB | ~0.03 |
| RDS db.t4g.micro | ~0.03 |
| Public IPv4 addresses | ~0.015 |
| **Total** | **≈ 0.27/h → a 4-hour session ≈ USD 1** |

Left running for a month it would be ≈ USD 190, so the session always ends with the teardown below. A budget alert (`budget_email` in `terraform.tfvars`) emails you if spend goes above plan.

## 3. Teardown checklist 🧹

1. `kubectl delete -k k8s/overlays/aws` and wait until the ALB is gone (EC2 console → Load balancers). The controller created it, not Terraform.
2. `cd infra/terraform && terraform destroy`.
3. Check, filtered by tag `Project=liveask`: no EKS cluster, EC2 instances, NAT gateway, Elastic IPs, load balancers, RDS instances or snapshots, EBS volumes.
4. Next day: Cost Explorer, confirm the spend stopped.
