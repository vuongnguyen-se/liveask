Windows gotchas found:
- psycopg async cannot use the default `ProactorEventLoop`; `conftest.py` and `migrate.py` select the selector loop on win32. Linux containers are unaffected.
- Use `127.0.0.1`, not `localhost`, in `DATABASE_URL` on Windows: `localhost` stalled the async pool.
- Local venv: `python -m venv .venv`, then `.venv\Scripts\python -m pip install -r app/requirements-dev.txt` (`.venv/` is git-ignored).
